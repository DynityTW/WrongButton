# 第 19 章　試算表（271–285）

> 由 `tools/s2/gen.py` 依 `tools/s2/ch19.py` 產生。

**主題**：試算表。The Button 是某一格裡的內容。點一下儲存格會選取它，上方的「內容列」會顯示它真正的內容（公式也會顯示）。點到 The Button 那一格就通關。

**工具**：顯示隱藏的欄、篩選、排序、內容列（公式）、名稱方塊（跳到某一格或某個名字）、取消合併、清除格式、標示規則、工作表分頁（含隱藏的工作表）、尋找、自動調整欄寬、復原。

**本章規則**：
- 點一般的儲存格只是選取，不算錯；點到冒牌貨（例如「The Butt0n」）或題目說不是的那一格才算錯。
- 每一關的線索都在畫面上：欄名跳號（B 之後是 D）、篩選的小圖示、「###」、內容列。
- 章內回扣：第 284 關問第 271 關 The Button 在哪一格（紀錄頁有記）。

---

### 271〈試算表〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：4 欄 × 6 列的表格，每一格都有字。
- **解法**：點寫著 The Button 的那一格。
- **線索**：格子裡的字。
- **提示**：①「我在某一格裡。」②「每一格的字都看看。」③「找到寫著「The Button」的那一格，點它。」
- **備註**：位置（隨機）會記在紀錄裡，第 284 關會問。

### 272〈隱藏的欄〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：欄名是 A、B、D（C 被隱藏）。
- **解法**：按「顯示 C 欄」，點 C 欄裡的 The Button。
- **線索**：欄名跳號。
- **提示**：①「欄名是 A、B、D。」②「少了 C。」③「按「顯示 C 欄」，我就在 C 欄裡。」

### 273〈篩選〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：A 欄是名稱、B 欄是狀態。上方顯示「篩選中：狀態＝正常」。
- **解法**：關掉篩選，點出現的 The Button。
- **線索**：篩選提示。
- **提示**：①「表格只顯示「正常」的列。」②「有一個篩選開著。」③「關掉「狀態：正常」的篩選，我就會出現。」

### 274〈最高分〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：十列，A 欄是名稱（按鈕 1、按鈕 2……）、B 欄是分數。
- **解法**：按 B 欄排序（高到低），點最上面那一列的名稱。
- **線索**：分數。
- **提示**：①「我是分數最高的那一個。」②「可以依分數排序。」③「按 B 欄的「排序」，最上面那一列的名稱就是我。」
- **備註**：點名稱以外的格子只是選取。點錯的名稱算錯。

### 275〈公式〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：A1 寫著「去看 B5 的公式」，B5 顯示 42。
- **解法**：點 B5，內容列顯示它的公式「＝The Button 在 D3」，點 D3。
- **線索**：內容列。
- **提示**：①「A1 叫妳去看 B5。」②「點 B5，看上面的內容列。」③「B5 的公式說我在 D3。點 D3。」

### 276〈名稱方塊〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：A1 寫著「我的名字是 BTN」。表格只顯示 A–D、1–6。
- **解法**：在名稱方塊輸入 BTN，按前往，再按出現的 The Button。
- **線索**：A1 的提示；名稱方塊。
- **提示**：①「我不在看得到的範圍裡。」②「左上角的名稱方塊可以跳到任何地方。」③「在名稱方塊輸入「BTN」，按「前往」，再按我。」

### 277〈合併儲存格〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：第 1、2 列被合併成一格「公告」。
- **解法**：按「取消合併」，點出現在 B2 的 The Button。
- **線索**：合併的大格子。
- **提示**：①「上面兩列被合併成一大格了。」②「我被蓋在下面。」③「按「取消合併」，再點我。」

### 278〈白色的字〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：表格中有一格看起來是空的（白色的字）。
- **解法**：按「清除格式」，點出現的 The Button。也可以點那一格看內容列。
- **線索**：看起來空的那一格。
- **提示**：①「有一格看起來是空的。」②「字是白色的。」③「按「清除格式」，我就看得到了。」

### 279〈標示規則〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：4 × 6 的數字表，只有一格大於 100。
- **解法**：打開「標示大於 100」，點被標示的那一格。
- **線索**：The Button 說的話。
- **提示**：①「我是唯一大於 100 的數字。」②「可以加標示規則。」③「打開「標示大於 100」，點被標出來的那一格。」

### 280〈隱藏的工作表〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：下方分頁：工作表 1、工作表 2，以及「取消隱藏工作表」。
- **解法**：按取消隱藏，切到工作表 3，點 The Button。
- **線索**：分頁。
- **提示**：①「我不在這張工作表。」②「分頁旁邊有東西。」③「按「取消隱藏工作表」，到工作表 3 找我。」

### 281〈尋找〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：很多格寫著「The Butt0n」「The Buton」之類的冒牌貨，只有一格是「The Button」。
- **解法**：用尋找輸入「The Button」，點被標示的那一格。
- **線索**：拼法；尋找。
- **提示**：①「好多格長得很像我。」②「有冒牌貨。」③「用「尋找」輸入 The Button，被標出來的那一格才是真的。」

### 282〈###〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：B 欄每一格都顯示「###」。
- **解法**：按「自動調整欄寬」，點 B 欄的 The Button。也可以點那一格看內容列。
- **線索**：###。
- **提示**：①「B 欄全部是 ###。」②「欄太窄了，字放不下。」③「按「自動調整欄寬」，我就出現了。」

### 283〈復原〉
- **任務**：找到 The Button 那一格，點它。
- **畫面**：上方寫著「已刪除 1 格」，旁邊有「復原」。
- **解法**：按「復原」，點回來的 The Button。
- **線索**：已刪除的提示。
- **提示**：①「有一格被刪掉了。」②「那一格就是我。」③「按「復原」，我就回來了。」

### 284〈哪一格〉
- **任務**：第 271 關，我在哪一格？
- **畫面**：四個選項（儲存格位置）。
- **解法**：從紀錄頁讀出位置。
- **線索**：暫停選單的「紀錄」有小圓點。
- **提示**：①「第 271 關我在哪一格？」②「紀錄裡有。」③「暫停 →「紀錄」看第 271 關的位置。」

- **畫面**：C 欄隱藏、篩選開著、The Button 那一格是白字。
