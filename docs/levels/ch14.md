# 第 14 章　換妳做（196–210）

> 由 `tools/s2/gen.py` 依 `tools/s2/ch14.py` 產生。

**主題**：換妳設計關卡給 The Button 玩。畫面是一個 3×3 的編輯器，左上角是「起點」（手指出發的地方）。零件有四種：

| 零件 | 作用 |
|---|---|
| 我（The Button） | 目標。一關只能有一個。 |
| 假的我 | 誘餌，會擋路。 |
| 線索 | 一張寫著「在這附近」的小卡，可以走過去。 |
| 牆 | 擋路。 |

手指從起點出發，只能上下左右走，不能穿過牆和假的我。按「試玩」，The Button 會照這一關的要求檢查，並說出第一個沒做到的地方。

**本章規則**：
- 要求都寫在畫面上；試玩沒過算一次錯，但它會明確說哪裡不對。
- 「公平」的規則就是這個遊戲自己的規則：只能有一個正解、要走得到、誘餌一多就要有線索。
- 章內回扣：第 209 關要把我放回第 196 關的位置（紀錄頁有記）。

### 196〈第一關〉
- **任務**：設計一關給我玩。
- **畫面**：空的編輯器。 要求：放一個我。
- **解法**：放一個「我」，試玩。
- **線索**：要求清單；試玩失敗時 The Button 說的話。
- **提示**：①「選「我」，再點一格。」②「放好之後按「試玩」。」③「隨便選一格放「我」，按「試玩」。」
- **備註**：放的位置會記在紀錄裡，第 209 關會用到。

### 197〈太簡單了〉
- **任務**：設計一關不那麼簡單的。
- **畫面**：空的編輯器。 要求：放一個我；至少兩個假的我。
- **解法**：放一個我和至少兩個假的我（我要走得到），試玩。
- **線索**：要求清單；試玩失敗時 The Button 說的話。
- **提示**：①「只有一個我太簡單了。」②「加一些假的我。」③「放一個我、兩個假的我，按「試玩」。」

### 198〈給點線索〉
- **任務**：設計一關，難但公平。
- **畫面**：空的編輯器。 要求：放一個我；至少三個假的我；我旁邊要有線索。
- **解法**：一個我、至少三個假的我、我旁邊（上下左右）放一張線索，試玩。
- **線索**：要求清單；試玩失敗時 The Button 說的話。
- **提示**：①「假的我一多，就要給玩家線索。」②「線索要放在我旁邊（上下左右）。」③「放一個我、三個假的我，在我旁邊放一張線索。」

### 199〈線索放錯了〉
- **任務**：修好這一關。
- **畫面**：預先擺好的一關：線索同時挨著我和假的我。 要求：放一個我；線索在我旁邊；線索不能在假的我旁邊。
- **解法**：把線索移到只挨著我、不挨著任何假的我的格子，試玩。
- **線索**：要求清單；試玩失敗時 The Button 說的話。
- **提示**：①「這關是別人做的，線索放錯了。」②「線索旁邊不能有假的我。」③「把線索移到只挨著我的那一格。」

### 200〈繞路〉
- **任務**：讓手指要走遠一點才到得了我。
- **畫面**：空的編輯器。 要求：放一個我；從起點要走 4 步以上。
- **解法**：例如牆放在 4、5，我放在 7：起點 → 2 → 3 → 6 → 9 → 8 → 7。
- **線索**：要求清單；試玩失敗時 The Button 說的話。
- **提示**：①「手指從左上角出發。」②「牆可以擋路。」③「用牆把路擋起來，讓最短的路也要走 4 步以上。」

### 201〈走不到〉
- **任務**：修好這一關。
- **畫面**：預先擺好的一關：三道牆把我圍起來。 要求：放一個我；我要走得到；至少兩道牆。
- **解法**：拆掉一道牆打開一條路（保留至少兩道），試玩。
- **線索**：要求清單；試玩失敗時 The Button 說的話。
- **提示**：①「手指現在走不到我。」②「拆一道牆就好。」③「拆掉擋住唯一一條路的那道牆，但留下至少兩道。」

### 202〈對稱〉
- **任務**：設計一關左右對稱的。
- **畫面**：空的編輯器（起點不算在對稱裡）。 要求：放一個我；左右對稱；至少兩道牆。
- **解法**：我放在中間那一欄，牆擺成左右對稱，試玩。
- **線索**：要求清單；試玩失敗時 The Button 說的話。
- **提示**：①「左邊放什麼，右邊對應的格子就放什麼。」②「我只有一個，所以只能放在中間那一欄。」③「我放中間那一欄，牆左右各一道。」

### 203〈最遠的地方〉
- **任務**：把我藏在手指走得到的最遠的地方。
- **畫面**：空的編輯器。 要求：放一個我；至少一道牆；我在最遠的格子。
- **解法**：擺至少一道牆，再把我放在步數最多的那一格，試玩。
- **線索**：要求清單；試玩失敗時 The Button 說的話。
- **提示**：①「「最遠」是走路的步數，不是直線距離。」②「先擺牆，再數每一格要走幾步。」③「例如牆放在 5，我放在 9（要走 4 步，最遠）。」

### 204〈兩條路〉
- **任務**：讓手指有兩條一樣短的路可以到我。
- **畫面**：空的編輯器。 要求：放一個我；最短的路有兩條以上；至少要走 3 步。
- **解法**：例如只放一個我在 6（3 步，有三條最短路），試玩。
- **線索**：要求清單；試玩失敗時 The Button 說的話。
- **提示**：①「從起點到我，最短的走法要有兩種以上。」②「沒有牆的時候，斜對角通常有很多走法。」③「例如我放在 6，什麼都不擋：起點往右或往下都可以。」

### 205〈一條路〉

- **畫面**：空的編輯器。 要求：放一個我；最短的路只有一條；至少要走 3 步。
- **解法**：例如牆放在 4、5，我放在 6，試玩。

### 206〈預算〉
- **任務**：只用三樣零件（包括我），讓手指走 4 步以上。
- **畫面**：空的編輯器，上方顯示「零件 0／3」。 要求：放一個我；零件最多三樣；從起點要走 4 步以上。

- **提示**：①「零件有限。」②「兩道牆加上我，剛好三樣。」③「牆放在 4、5，我放在 7。」

### 207〈它的要求〉
