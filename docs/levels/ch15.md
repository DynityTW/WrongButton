# 第 15 章　看不見（211–225）

> 由 `tools/s2/gen.py` 依 `tools/s2/ch15.py` 產生。

**主題**：無障礙功能變成謎題的語彙。

- **朗讀器關卡**（211–216、222–225）：畫面是黑的，只能用遊戲內的朗讀器：「上一個」「下一個」「下一個標題」「點兩下」「離開群組」。朗讀器會念出目前項目的名稱、角色和外觀。替代文字可能會說謊，但朗讀器念出的 The Button 外觀（眼睛、嘴角）不會。
- **協助工具關卡**（217–221）：畫面上有一個問題（分不出顏色、聽不到聲音、按不到、停不下來、看不清楚），要在關卡裡的「協助工具」打開對的那一項。

**本章規則**：
- 不要求玩家打開系統的 TalkBack：朗讀器全部在遊戲裡。
- 朗讀器本身也可以用 TalkBack 操作：控制鈕都是一般按鈕，念出的內容是即時更新的文字。
- 章內回扣：第 224 關問第 211 關 The Button 是清單上的第幾個（紀錄頁有記）。

---

### 211〈朗讀器〉
- **任務**：用朗讀器找到我，點兩下。
- **畫面**：畫面是黑的，下方是朗讀器。清單上有標題、文字、「取消」和 The Button（位置隨機）。
- **解法**：按「下一個」直到念出「The Button，按鈕」，再按「點兩下」。
- **線索**：朗讀器念出的名稱。
- **提示**：①「畫面看不見，用下面的朗讀器。」②「按「下一個」，聽它念每一項。」③「念到「The Button，按鈕」時，按「點兩下」。」
- **備註**：The Button 在清單上的位置會記在紀錄裡，第 224 關會問。

### 212〈沒有名字〉
- **任務**：找到我，點兩下。
- **畫面**：畫面是黑的，下方是朗讀器。四個沒有名字的「按鈕」，其中一個後面跟著一段文字「上一個按鈕是 The Button」。
- **解法**：念到那段文字後按「上一個」，再點兩下。
- **線索**：說明文字。
- **提示**：①「這裡的按鈕都沒有名字。」②「有一段文字在說明前一個按鈕。」③「找到「上一個按鈕是 The Button」那段文字，按「上一個」回去，點兩下。」

### 213〈替代文字〉
- **任務**：找到真正的我，點兩下。
- **畫面**：畫面是黑的，下方是朗讀器。兩個項目都念成「The Button：『我是真的』」，後面接著外觀描述。
- **解法**：選外觀是「直視、嘴角對稱」的那一個，點兩下。
- **線索**：朗讀器念的外觀。
- **提示**：①「兩個都說自己是 The Button。」②「朗讀器也會念出外觀。」③「眼睛看旁邊、嘴角翹起的那個在說謊。點另一個。」

### 214〈標題〉
- **任務**：找到我，點兩下。
- **畫面**：畫面是黑的，下方是朗讀器。三節，每節一個標題加五個「不是我」按鈕；The Button 在第三節。
- **解法**：按「下一個標題」跳到第三節，再往下找。
- **線索**：「下一個標題」鈕。
- **提示**：①「清單很長。」②「有「下一個標題」可以跳。」③「跳到第三個標題「其他」，再往下找 The Button。」
- **備註**：也可以一直按「下一個」，只是比較久。

### 215〈在誰後面〉
- **任務**：找到我，點兩下。
- **畫面**：畫面是黑的，下方是朗讀器。開頭一段文字「我在『儲存』的後面」，接著儲存、分享、刪除和三個沒有名字的按鈕，順序隨機。
- **解法**：找到「儲存」，下一個就是 The Button。
- **線索**：開頭的文字。
- **提示**：①「開頭有一段文字告訴妳我在哪裡。」②「我沒有名字，只是「按鈕」。」③「我在「儲存」的後面：念到「儲存」後，再按一次「下一個」。」

### 216〈通知〉
- **任務**：找到我，點兩下。
- **畫面**：畫面是黑的，下方是朗讀器。六個沒有名字的按鈕，最後一項是通知「The Button 在第 N 個按鈕」。
- **解法**：讀通知，找到第 N 個按鈕，點兩下。
- **線索**：通知。
- **提示**：①「有一則通知告訴妳我在哪。」②「通知在清單最後面。」③「按「上一個」從最後一項開始聽，通知說我是第幾個按鈕。」

### 217〈顏色〉
- **任務**：按綠色的那一顆。
- **畫面**：兩顆灰色的按鈕（一紅一綠，被黑白濾鏡蓋住）。下方是協助工具。
- **解法**：打開「顯示文字標籤」，按「綠」。
- **線索**：黑白的畫面；協助工具。
- **提示**：①「畫面是黑白的。」②「協助工具可以加上文字標籤。」③「打開「顯示文字標籤」，按標著「綠」的那一顆。」
- **備註**：打開標籤前按任何一顆都算錯。

### 218〈字幕〉
- **任務**：照我說的按。
- **畫面**：The Button 的泡泡只有音符。兩顆候選按鈕。下方是協助工具。
- **解法**：打開「字幕」，照字幕（例如「按右邊那顆」）按。
- **線索**：音符；協助工具。
- **提示**：①「我說話了，但妳聽不到。」②「協助工具裡有字幕。」③「打開「字幕」，照字幕說的按。」

### 219〈太小了〉
- **任務**：按下我。
- **畫面**：一顆很小的 The Button。下方是協助工具。
- **解法**：打開「放大觸控範圍」，再按它。
- **線索**：它很小；協助工具。
- **提示**：①「我太小了。」②「協助工具可以放大觸控範圍。」③「打開「放大觸控範圍」，再按我。」
- **備註**：打開前按它算錯（沒按到）。

### 220〈停不下來〉
- **任務**：按下我。
- **畫面**：The Button 在畫面上左右跑。下方是協助工具。
- **解法**：打開「減少動態效果」，再按它。
- **線索**：它在動；協助工具。
- **提示**：①「我一直在動。」②「協助工具可以減少動態效果。」③「打開「減少動態效果」，等我停下來再按。」
- **備註**：打開前按它算錯。跑動不靠反應速度：打開之後它會停在原地。

### 221〈看不清楚〉
- **任務**：照上面的字按。
- **畫面**：上方一行很淡的指示（例如「按中間那顆」），三顆候選。下方是協助工具。
- **解法**：打開「高對比」，照指示按。
- **線索**：淡淡的字；協助工具。
- **提示**：①「上面有一行很淡的字。」②「協助工具可以提高對比。」③「打開「高對比」，照那行字按。」
- **備註**：TalkBack 本來就讀得到那行字，所以使用 TalkBack 的玩家不需要打開高對比。

### 222〈群組〉
- **任務**：找到我，點兩下。
- **畫面**：畫面是黑的，下方是朗讀器。三個群組，每個三項；The Button 在其中一個群組裡。
- **解法**：在群組上點兩下進去聽，不在就「離開群組」換下一個。
- **線索**：朗讀器念「群組，3 項」。
- **提示**：①「清單裡有群組。」②「「下一個」會跳過群組裡面。」③「在群組上點兩下可以進去，「離開群組」回到外面。我在其中一個群組裡。」

### 223〈三個我〉
- **任務**：找到真正的我，點兩下。
- **畫面**：畫面是黑的，下方是朗讀器。三個項目都念成「The Button：『我在這裡』」，外觀不同。
- **解法**：選外觀誠實的那一個，點兩下。
- **線索**：朗讀器念的外觀。
- **提示**：①「三個都說自己是 The Button。」②「只有一個說的是實話。」③「聽外觀：直視、嘴角對稱的那一個才是真的。」

### 224〈第幾個〉
- **任務**：第 211 關，我是清單上的第幾個？
- **畫面**：四個選項：第 1、2、3、4 個。
- **解法**：從紀錄頁讀出位置。
- **線索**：暫停選單的「紀錄」有小圓點。
- **提示**：①「那是第 211 關〈朗讀器〉的事。」②「紀錄裡有。」③「暫停 →「紀錄」看第 211 關的位置。」
- **備註**：章內回扣。沒有紀錄時當作第 4 個並重新記下。

### 225〈黑暗中的會議〉
- **任務**：找到真正的我，點兩下。
- **畫面**：畫面是黑的，下方是朗讀器。三節，每節一個標題和一個群組；每個群組裡有一個自稱 The Button 的項目，只有一個外觀誠實。
- **解法**：逐一進群組聽外觀，找到誠實的那一個，點兩下。
- **線索**：外觀描述。
- **提示**：①「標題、群組、冒牌貨，全部都有。」②「每個群組裡都有一個「The Button」。」③「用標題跳、進群組聽外觀，只有一個是誠實的臉。」
- **備註**：章末頭目。
