# 第 20 章　迷路（286–300）

> 由 `tools/s2/gen.py` 依 `tools/s2/ch20.py` 產生。

**主題**：導覽。The Button 住在一個小 App 的某一頁，要妳用各種導覽方式找到它：底部分頁、側邊選單、返回、麵包屑、文中連結、網址列、瀏覽紀錄、各自記得位置的分頁、擋路的彈窗、很長的頂部分頁、兩層選單、沒有返回鈕的全螢幕頁、房間迷宮。

**本章規則**：
- 系統返回永遠離開關卡（和全遊戲一樣）；這一章的「返回」是畫面裡那個 App 自己的 ← 鈕。
- 畫面上方永遠顯示目前在哪一頁。
- 點到冒牌的頁面不算錯；被彈窗騙去登入、或在題目說不是的地方按下去才算錯。
- 章內回扣：第 299 關問第 286 關 The Button 在哪個分頁（紀錄頁有記）。
- 第 300 關是第二季的最後一關，但不是故事的結局：它只是一個用上所有導覽方式的頭目關。

---

### 286〈分頁〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：底部三個分頁：首頁、探索、我的。The Button 在其中一個（隨機）。
- **解法**：點對的分頁，按 The Button。
- **線索**：底部分頁。
- **提示**：①「下面有三個分頁。」②「我在其中一個。」③「每個分頁都點點看。」
- **備註**：分頁會記在紀錄裡，第 299 關會問。

### 287〈側邊選單〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：底部分頁和左上角的 ☰。
- **解法**：打開 ☰，點「收藏」，按 The Button。
- **線索**：☰。
- **提示**：①「分頁裡都沒有我。」②「左上角有 ☰。」③「打開 ☰ 側邊選單，點「收藏」。」

### 288〈上一頁〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：一開始就在很深的頁面：首頁 › 商店 › 文具 › 結帳。The Button 在「文具」。
- **解法**：按畫面裡的 ← 一次，按 The Button。
- **線索**：The Button 說的話；←。
- **提示**：①「我在上一頁。」②「畫面裡有 ← 返回鈕。」③「按畫面裡的 ←（不是系統返回）。」
- **備註**：系統返回會離開關卡（全遊戲一致），畫面裡的 ← 才是這個 App 的返回。

### 289〈麵包屑〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：很深的頁面，上方有麵包屑：首頁 › 商店 › 文具 › 筆 › 原子筆 › 藍色。The Button 在「商店」。
- **解法**：點麵包屑的「商店」，按 The Button。
- **線索**：麵包屑。
- **提示**：①「上面那一排是走過來的路。」②「每一段都可以點。」③「點麵包屑裡的「商店」。」

### 290〈連結〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：一篇文章，其中「這裡」是連結（有底線），另外還有一般的按鈕。
- **解法**：點文章裡的「這裡」，按 The Button。
- **線索**：有底線的字。
- **提示**：①「文章裡有一個字可以點。」②「有底線的字是連結。」③「點文章裡的「這裡」。」

### 291〈網址〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：上方有網址列；The Button 說「我的地址是 wb://button」。
- **解法**：在網址列輸入 wb://button，按前往，按 The Button。
- **線索**：The Button 說的地址。
- **提示**：①「我告訴妳我的地址了。」②「上面有網址列。」③「在網址列輸入 wb://button，按「前往」。」

### 292〈瀏覽紀錄〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：首頁有一個「瀏覽紀錄」，裡面是最近去過的頁面。
- **解法**：打開瀏覽紀錄，點「The Button 的家」，按 The Button。
- **線索**：瀏覽紀錄。
- **提示**：①「妳之前來過我家。」②「瀏覽紀錄裡有。」③「打開「瀏覽紀錄」，點「The Button 的家」。」

### 293〈走到一半〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：目前在「首頁」分頁。「探索」分頁裡之前已經走到第三層（The Button 在那裡）。
- **解法**：點「探索」分頁，按 The Button。
- **線索**：The Button 說的話。
- **提示**：①「妳剛剛在「探索」走到一半。」②「每個分頁會記得自己走到哪。」③「點「探索」分頁，會回到妳剛剛走到的地方。」
- **備註**：點「探索」會回到它自己記得的頁面，不是回到探索的第一頁。

### 294〈請先登入〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：「請先登入」彈窗擋住畫面：大按鈕「登入」，下面一行小字「以訪客身分繼續」。
- **解法**：按「以訪客身分繼續」，到「我的」分頁按 The Button。
- **線索**：小字。
- **提示**：①「有一個彈窗擋住了。」②「不用登入。」③「按彈窗下面的「以訪客身分繼續」。」
- **備註**：按「登入」算錯（這個 App 沒有帳號）。

### 295〈很多分頁〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：上方一排可以橫向捲動的分頁，共十幾個，The Button 在最右邊。
- **解法**：把分頁列往右捲到底，點「The Button」分頁，按 The Button。
- **線索**：分頁列可以捲動。
- **提示**：①「上面的分頁很多，看不完。」②「分頁那一排可以往右滑。」③「把頂部分頁往右滑到最後，點「The Button」。」

### 296〈兩層選單〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：☰ 側邊選單裡有一個「更多 ▸」可以展開。
- **解法**：打開 ☰，展開「更多」，點「進階」，按 The Button。
- **線索**：▸。
- **提示**：①「側邊選單裡有一個可以展開的群組。」②「群組裡還有東西。」③「☰ → 展開「更多」→「進階」。」

### 297〈死路〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：一開始在一個全螢幕的公告頁：沒有 ←、沒有分頁，右上角有 ×。
- **解法**：按 ×，到「我的」分頁按 The Button。
- **線索**：×。
- **提示**：①「這一頁沒有返回鈕，也沒有分頁。」②「右上角有一個 ×。」③「按右上角的 ×，回到首頁，再到「我的」按我。」

### 298〈迷宮〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：六個房間，每個房間有往北／南／東／西的門。The Button 在最深的房間。
- **解法**：入口 → 北 → 東 → 北（也可以用 ← 返回重來）。
- **線索**：門的名稱；入口的告示。
- **提示**：①「每個房間有幾扇門。」②「房間名稱會告訴妳方向。」③「從入口：往北 → 往東 → 往北，就是我的房間。」

### 299〈哪個分頁〉
- **任務**：第 286 關，我住在哪個分頁？
- **畫面**：三個選項：首頁、探索、我的。
- **解法**：從紀錄頁讀出分頁。
- **線索**：暫停選單的「紀錄」有小圓點。
- **提示**：①「第 286 關我住在哪個分頁？」②「紀錄裡有。」③「暫停 →「紀錄」看第 286 關的分頁。」
- **備註**：章內回扣。沒有紀錄時當作「我的」並重新記下。

### 300〈第 300 關〉
- **任務**：找到我住的那一頁，按我。
- **畫面**：「請先登入」彈窗擋住畫面。☰ 裡的「更多」藏著「進階」，「進階」的文章裡有連結；The Button 在連結頁的前一頁。
- **解法**：以訪客身分繼續 → ☰ → 展開「更多」→「進階」→ 點文章裡的「這裡」→ 按 ← → 按 The Button。
- **線索**：彈窗的小字；▸；文章裡有底線的字；The Button 說「我在連結的前一頁」。
- **提示**：①「彈窗、選單、連結、返回，全部都要用到。」②「一步一步來。」③「以訪客身分繼續 → ☰ → 展開「更多」→「進階」→ 點文章裡的「這裡」→ 按 ← 一次 → 按我。」
- **備註**：第二季的頭目。不是故事結局：之後還可以繼續加章節。
