# 第 18 章　檔案（256–270）

> 由 `tools/s2/gen.py` 依 `tools/s2/ch18.py` 產生。

**主題**：檔案管理員。The Button 是一個叫「The Button.btn」的檔案，打開它就通關。它可能被藏起來、丟進垃圾桶、改了名字、壓縮、或混在一堆一模一樣的檔案裡。

**工具列**：上一層、顯示隱藏檔案、顯示副檔名、排序（名稱／日期／大小）、選取（多選後刪除或移動）、搜尋、垃圾桶。每個檔案旁邊有 ⓘ（內容：大小、日期、作者）和 ✎（重新命名）。

**本章規則**：
- 打開不對的檔案算錯，The Button 會說那是什麼（照片、文字檔、冒牌貨）。
- 條件還沒達成時打開 The Button，它會說還差什麼（例如「我在垃圾桶裡，先還原」）。
- 章內回扣：第 269 關問第 256 關 The Button 在哪個資料夾（紀錄頁有記）。
