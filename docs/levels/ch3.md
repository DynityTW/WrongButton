# 第 3 章　什麼才算按鈕（31–45）

**主題**：重新定義「按鈕」。凡是按得下去的東西都算，而「按」也不只一種方式。
**讀臉**：從這章開始，它在任何關卡都可能說謊，表情規則照舊。
**共通規則**：每關都有單指、不限時的解法，以及 TalkBack 可用的替代操作。

---

### 31〈連結〉
- **任務**：按下按鈕。
- **畫面**：一段介紹按鈕的文字，其中「按鈕」兩個字有底線，是連結的顏色。下方有一張很大的「按鈕」圖片。
- **解法**：點那個有底線的字，The Button 從字裡跳出來，再按它。
- **線索**：底線；它的聲音「我在字裡行間。」；按到大圖時說「那是一張按鈕的截圖。」
- **提示**：①「這段文字裡，有兩個字長得不一樣。」②「有底線的字通常可以點。」③「點文字裡有底線的『按鈕』。」
- **備註**：按到大圖算錯。

### 32〈沒有字〉
- **任務**：按下按鈕。
- **畫面**：一排五個只有抽象圖示的按鈕（圓、方、三角、星、菱形），沒有文字。
- **解法**：長按圖示會出現工具提示（「分享」「搜尋」「刪除」「設定」「The Button」）。找到它之後點下去。
- **線索**：它說「我換了一張臉。這裡沒人寫字，真沒禮貌。」
- **提示**：①「這些圖示都沒有說明文字。」②「不知道圖示是什麼的時候，妳會怎麼試？」③「長按每個圖示看名稱，找到 The Button 再點。」
- **備註**：TalkBack 會直接讀出名稱。點錯算錯。

### 33〈按住〉
- **任務**：按下按鈕。
- **畫面**：The Button 外面有一圈空的進度環。
- **解法**：按住不放，環會慢慢填滿，滿了才算按下。中途放開就歸零。
- **線索**：輕點一下，環會填一小段再退回；它說「輕輕碰一下不算。按久一點，我才知道妳是認真的。」
- **提示**：①「點它的時候，外面那圈動了一下。」②「有些操作要『按住』才算數。」③「按住我不放，直到外圈填滿。」
- **備註**：沒有時間上限，只要求持續按住 1.5 秒。TalkBack 提供自訂動作「按住」。

### 34〈都算〉
- **任務**：把畫面上每一顆按鈕都按一次。
- **畫面**：The Button、Switch、Checkbox、Chip、文字連結、分段按鈕。上方的計數 Chip 顯示「已按 0／8」。
- **解法**：畫面上六個都按過之後還差兩個：頂端列的暫停鈕和提示鈕也算。
- **線索**：撥動 Switch 時計數會加一；到 6／8 時它說「還差兩個。它們一直都在最上面。」
- **提示**：①「計數是 8，妳數到幾個？」②「不是長得像按鈕的才算。」③「畫面上六個元件，加上最上面的暫停和提示，都按一次。」

### 35〈搜尋鍵〉
- **任務**：按下按鈕。
- **畫面**：一個搜尋欄「搜尋按鈕…」，下方寫著「輸入後按搜尋」。畫面上沒有搜尋按鈕。
- **解法**：輸入任何字，按鍵盤右下角的搜尋鍵。結果只有一筆，就是 The Button。
- **線索**：「按搜尋」那三個字；它說「那顆按鈕不在畫面上，在妳手指底下。」
- **提示**：①「畫面上沒有搜尋按鈕。」②「鍵盤上也有按鈕。」③「隨便輸入一個字，按鍵盤右下角的搜尋鍵。」
- **備註**：使用系統鍵盤（IME 動作鍵）。外接鍵盤按 Enter 也可以。

### 36〈滑動以確認〉
- **任務**：按下按鈕。
- **畫面**：一條軌道，左端的把手是 The Button，軌道上寫「滑動以按下 →」。
- **解法**：把它從左拖到右。沒到底放開會彈回去。
- **線索**：軌道上的文字；點它時說「這次我不是用按的。」
- **提示**：①「軌道上寫了字。」②「有些確認是用滑的。」③「按住我，一路拖到軌道最右邊。」
- **備註**：TalkBack 提供自訂動作「滑到底」。

### 37〈今日推薦〉
- **任務**：按下按鈕。
- **畫面**：一疊卡片，最上面寫「今日推薦按鈕 1／5」，卡片上是沒有臉的按鈕和「按下」。
- **解法**：把卡片一張張滑掉，第 5 張是 The Button。
- **線索**：卡片堆的邊緣看得到層次；計數「1／5」。
- **提示**：①「這是一疊卡片，不是一張。」②「不想要的卡片，通常怎麼處理？」③「把前四張滑掉，第五張是我。」
- **備註**：按前四張的「按下」算錯（「那是推薦的，不是我。」）。

### 38〈＋〉
- **任務**：按下按鈕。
- **畫面**：空白頁面，右下角一顆「＋」FAB。
- **解法**：點 FAB 會展開三個小選項（筆記、相片、同事），同時主 FAB 變成 The Button 的臉。再按一次主 FAB。
- **線索**：展開時它說「選單打開的時候，中間那顆變了。」
- **提示**：①「畫面上只有一顆按鈕。」②「它展開之後，有什麼不一樣？」③「點『＋』展開，再按一次變成我的臉的那一顆。」
- **備註**：按到小選項算錯。

### 39〈收件者〉
- **任務**：按下按鈕。
- **畫面**：一個輸入列「收件者：[同事 ×] [同事 ×] [The Button ×]」，三個輸入 Chip，其中一個的頭像有臉。
- **解法**：點那個 Chip 的本體，打開詳細卡片，裡面是可以按的 The Button。
- **線索**：Chip 上的頭像；按到它的 × 會被移除，同時出現「復原」訊息條，它說「妳把我移除了。」
- **提示**：①「三個收件者，長得不太一樣。」②「Chip 有兩個可以點的地方。」③「點有臉那個 Chip 的名字，不是 ×，打開後按我。」
- **備註**：按到 × 不算錯，可以復原。

### 40〈清單／格狀〉
- **任務**：按下按鈕。
- **畫面**：清單檢視，六列的名稱都被截斷成「按鈕…」。右上有「清單｜格狀」分段按鈕。
- **解法**：切到格狀檢視，會出現縮圖，有臉的那張就是它。
- **線索**：分段按鈕；它說「用清單看，我們都長得一樣。」
- **提示**：①「這些名字都被截斷了。」②「右上角可以換一種看法。」③「切到『格狀』，按有臉的那一格。」
- **備註**：在清單檢視亂按算錯。

### 41〈放開才算〉
- **任務**：按下按鈕。
- **畫面**：四個一模一樣的 The Button，其中三個只是圖片。
- **解法**：手指按住其中一個但不放開。真的那個會被壓扁，圖片不會有反應。想換一個試，就把手指滑出去再放開，這樣不算按。找到真的再正常按下。
- **線索**：它說「真的按鈕，碰到會有反應。放開才算數。」
- **提示**：①「四個裡只有一個是真的。」②「按下去還沒放開的時候，仔細看。」③「按住觀察有沒有被壓扁；不是就把手指滑開再放。找到會被壓扁的那個再按。」
- **備註**：在圖片上放開算錯。TalkBack 會讀出「圖片」和「按鈕」的角色差異。

### 42〈顯示〉
- **任務**：按下按鈕。
- **畫面**：一個半透明、標著「停用中」的 The Button。旁邊有一塊空白區域，右邊有個「眼睛」圖示。
- **解法**：點眼睛圖示（顯示／隱藏的慣例），空白處會出現真正的 The Button，按它。
- **線索**：眼睛圖示；停用的那個說「我是展示用的。」（實）
- **提示**：①「這個是停用的，那能按的在哪？」②「眼睛圖示通常是做什麼的？」③「點眼睛圖示，把藏起來的我顯示出來。」

### 43〈排行榜〉（記憶回扣）
- **任務**：按下按鈕。
- **畫面**：一張表格，列出妳玩過的每一關，欄位是「關卡｜按錯｜耗時」。欄位標題可以點。
- **解法**：它躲在妳按錯最多的那一關。點「按錯」欄位標題排序，最上面那列點開就是它。如果妳一次都沒錯過，改成躲在耗時最長的那一關。
- **線索**：它說「我躲在妳最丟臉的那一關裡。」；欄位標題旁有排序箭頭。
- **提示**：①「這張表記的是妳自己。」②「表格的欄位標題可以點。」③「點『按錯』排序，打開第一列。都沒錯過的話，改點『耗時』。」
- **備註**：點錯列算錯。

### 44〈團體照〉（記憶回扣）
- **任務**：按下按鈕。
- **畫面**：一張很大的「團體照」，10×10 個小按鈕，只有一個有臉。可以縮放和平移。它說「我在最後一排。」，是說謊臉。
- **解法**：放大照片找有臉的那個，它不在最後一排。
- **記憶**：它記得妳在〈至少 48dp〉用哪種方式放大，把那種方式關掉並拿來吐槽（「這次不准用兩根手指。」）。另一種手勢和畫面上的「＋／－」鈕都還能用。
- **線索**：說謊臉；「＋／－」縮放鈕。
- **提示**：①「一百個裡只有一個有臉。」②「它說在最後一排的時候，眼睛看哪裡？」③「用『＋』放大後平移尋找。它不在最後一排。」
- **備註**：「＋／－」鈕就是單指解法。
