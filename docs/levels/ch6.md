# 第 6 章　改版（76–90）

**主題**：失去。The Button 被「Button 2」換掉。
**Button 2**：光滑的藥丸形、漸層色、沒有臉。說話永遠正面，句尾帶 ✨。它說的話有真有假，但沒有臉可以讀，這就是這一章的困難所在。
**劇情**：玩家先發現讀臉失效，接著在介面的角落找回舊 The Button 的碎片（兩隻眼睛、嘴、名字、記憶），把它拼回來，最後自己選擇要留下誰。

**本章規則**：
- 全部是遊戲內的劇情。不出現任何像系統更新、系統設定、系統對話框的畫面。
- 規格要求「對話框上看得到 The Button 的臉」。這一章它不在場，所以每個對話框的邊緣都會有它的眼睛探出來偷看。這既符合規定，也讓玩家知道它還在。**這個做法需要妳確認。**
- 收集到的碎片會顯示在紀錄頁，「讓 The Button 忘記我」會一併清除。

### 76〈2.0〉
- **任務**：按下按鈕。
- **畫面**：正中央是 Button 2。
- **解法**：按下去，立刻通關。
- **目的**：和第 1 關對照。沒有臉，沒有吐槽，結算只有一句「感謝您的按壓。✨」。紀錄頁的標題變成「（舊版資料）」。
- **提示**：①「按下去。」②「真的，就這樣。」③「按它。然後想想少了什麼。」

### 77〈新功能〉
- **任務**：找出被移除的東西。
- **畫面**：一張「新功能」卡片：「✨ 更圓潤的外觀」「✨ 更快的回應」，底下有小字「顯示完整日誌」。
- **解法**：點「顯示完整日誌」，再點一次「更多」，捲到最底有一行被劃掉的「移除：表情」。點它，會出現一張很小的舊臉縮圖，再按那張縮圖。
- **線索**：小字連結；刪除線。
- **提示**：①「這份清單只寫了好事。」②「更新日誌通常還有完整版。」③「點『顯示完整日誌』和『更多』，捲到底點『移除：表情』，再按出現的縮圖。」
- **台詞**：Button 2「這是舊版的殘留畫面，請忽略。✨」

### 78〈永遠微笑〉
- **任務**：按下正確的按鈕。
- **畫面**：Button 2 當顧問：「是左邊。✨」。它沒有臉，無從判斷。旁邊站著同事，下方有問題 Chip，每回合只能問一題：
  - 「它說的是實話嗎？」
  - 「你喜歡新版嗎？」
  - 「正確的是哪一顆？」
- **解法**：每回合問同事「它說的是實話嗎？」，同事回「是。」或「這一句不是。」，再決定。三回合。
- **線索**：沒有臉可讀；同事不會說謊（第 24 關學過）。
- **提示**：①「它沒有臉，妳看不出真假。」②「這裡還有誰不會說謊？」③「每回合問同事『它說的是實話嗎？』，再照答案選。」
- **備註**：這一關讓玩家第一次明確感覺到失去那張臉的代價。

### 79〈您的意見〉
- **任務**：送出意見。
- **畫面**：回饋表單：評分、類別下拉、說明欄。類別裡沒有「把舊的還我」。
- **解法**：類別捲到最底選「其他」，在新出現的說明欄填字，再送出（第 64 關的做法）。
- **線索**：下拉選單的捲軸。
- **提示**：①「這些類別都不是妳想說的。」②「妳在申請表學過這一招。」③「類別捲到底選『其他』，填寫說明後送出。」
- **結尾**：自動回覆「感謝回饋！✨」，底下有一行很小的字「已讀：The Button」。這是它第一次回應。

### 80〈快取〉
- **任務**：找回它的一部分。
- **畫面**：遊戲樣式的「關於 Button 2」頁面。兩列：「資料」「快取：1 個檔案」，下方是很顯眼的「清除快取」。Button 2 說「建議清除，以獲得最佳體驗 ✨」。
- **解法**：不要清除。點「快取」那一列，裡面有一個檔案 `face_old.png`，點開取得**左眼**。
- **線索**：「1 個檔案」；Button 2 太熱心了。
- **提示**：①「快取裡還有東西。」②「它為什麼這麼希望妳清掉？」③「點『快取』那一列，別按清除，打開裡面的檔案。」
- **備註**：按了「清除快取」算錯，同時出現「復原」訊息條，可以救回來。

### 81〈實驗組〉
- **任務**：找回它的一部分。
- **畫面**：Button 2 在畫面中央。右上角有一個小 Chip 寫著「A」。
- **解法**：下拉重新整理，Chip 變成「B」，畫面中央變成舊 The Button 的剪影，嘴的位置有一塊可以點的碎片。點它取得**嘴**。再重新整理會回到 A。
- **線索**：角落的「A」；呼應第 2 關。
- **提示**：①「右上角那個『A』是什麼？」②「有 A，就有 B。怎麼換？」③「下拉重新整理切到 B，點剪影上的嘴。」

### 82〈快速導覽〉
- **任務**：找回它的一部分。
- **畫面**：五步的導覽泡泡，每步有一個聚光圈（圈外變暗、不能點）和「知道了」。第四步的泡泡寫著「這裡什麼都沒有，請直接按『知道了』。✨」，聚光圈裡隱約有一個臉的輪廓。
- **解法**：到第四步時，點聚光圈裡面，不要按「知道了」。取得**右眼**。
- **線索**：只有第四步特別強調「什麼都沒有」；圈裡的輪廓。
- **提示**：①「五個步驟裡，有一步的說明很奇怪。」②「聚光圈裡面是可以點的。」③「第四步不要按『知道了』，點亮著的圈圈裡面。」
- **備註**：錯過了可以按「上一步」回去，導覽也會循環。

### 83〈朗讀畫面〉
- **任務**：找回它的一部分。
- **畫面**：Button 2 和一個「朗讀畫面」開關。
- **解法**：打開開關。畫面上每個元件會出現外框和說明字幕。Button 2 的說明沒更新，仍是「珊瑚紅的按鈕，看著妳。」。旁邊空白處多了一個外框，寫著「The Button 的名字（隱藏）」。點它取得**名字**。
- **線索**：開關；它在第 77 關說過舊的東西都還「殘留」著。
- **提示**：①「看不到的東西，不一定不存在。」②「讓畫面自己說出它有什麼。」③「打開『朗讀畫面』，點那個寫著『The Button 的名字』的外框。」
- **備註**：這是遊戲內的功能，不需要開啟系統的 TalkBack。

### 84〈歷史版本〉
- **任務**：找回它的一部分。
- **畫面**：版本清單，從「2.0（目前）」往下排，每列的「還原」都是停用的。清單底部有「載入更多」。
- **解法**：按三次「載入更多」一路到「0.2」，點開它的說明「初版。它會說謊。」，下方有「下載備份」。取得**記憶**（`memory.bak`）。
- **線索**：「載入更多」；較舊的版本說明越來越短。
- **提示**：①「這份清單沒有到底。」②「它最早的版本是哪一版？」③「一直按『載入更多』到 0.2，點開後按『下載備份』。」

### 85〈空白的紀錄〉
- **任務**：還原紀錄。
- **畫面**：Button 2 說「Button 2 尊重您的隱私，不保留任何紀錄。✨」。暫停選單的「紀錄」頁是空的，右上角有「⋮」。
- **解法**：紀錄頁的「⋮」→「匯入備份」→ 選 `memory.bak`。紀錄回來了。
- **線索**：紀錄的小圓點；空白頁上的「⋮」。
- **提示**：①「妳手上有一份備份。」②「空白的紀錄頁，右上角多了什麼？」③「打開『紀錄』，點『⋮』選『匯入備份』。」
- **結尾**：紀錄頁第一列出現它的聲音：「第 1 關：妳花了 {x} 秒才按下我。……我還記得。」

### 86〈拼回來〉
- **任務**：把它的臉拼回來。
- **畫面**：Button 2 光滑的表面，旁邊放著三塊碎片（左眼、右眼、嘴）。可以拖曳，靠近中線和水平線時會出現對齊參考線。
- **解法**：把兩隻眼睛放在對稱的位置，嘴放正，也就是誠實的臉。放好後它醒過來。
- **線索**：對齊參考線；妳已經知道誠實的臉長什麼樣。
- **提示**：①「妳看過這張臉很多次。」②「它說實話的時候，眼睛和嘴是什麼樣子？」③「兩隻眼睛左右對稱，嘴放正。跟著參考線放。」
- **備註**：放歪成說謊的臉時，它會醒來說「我沒事。」，然後又散開（不算錯）。TalkBack 提供「放到左眼位置」等自訂動作。

### 87〈它的名字〉
- **任務**：把名字還給它。
- **畫面**：有臉了，但名牌還寫著「Button 2」。
- **解法**：長按名牌 →「重新命名」→ 輸入欄會跳出建議「The Button」（來自第 83 關的碎片），選它。
- **線索**：名牌；呼應第 14 關（⋮）它說的「我的名字很好，謝謝。」
- **提示**：①「臉回來了，還有什麼不對？」②「想改名字的時候，妳會對那個名字做什麼？」③「長按名牌選『重新命名』，選建議的『The Button』。」

### 88〈兩個顧問〉
- **任務**：按下正確的按鈕。
- **畫面**：The Button（有臉）和 Button 2（沒臉）各說一句，內容互相矛盾。兩顆候選。
- **解法**：只看 The Button 的臉，依它的真假推答案，不理 Button 2。三回合，其中有一回合 The Button 在說謊。
- **線索**：只有一邊讀得出真假。
- **提示**：①「兩個說的不一樣。」②「哪一個的話，妳驗證得了？」③「只看 The Button 的臉。它說謊就反著聽，Button 2 說什麼都別管。」
- **台詞**：通關後 The Button「一個看得出在說謊的，跟一個永遠微笑的。妳選了我。」（實）

### 89〈一律採用〉
- **任務**：按下 The Button。
- **畫面**：每次要按，都會跳出遊戲樣式的選擇框：「要用哪一個按鈕？」。選項是 Button 2（預先反白）和 The Button。下方有「僅此一次」和「一律採用」。
- **解法**：選 The Button 再按「一律採用」。只按「僅此一次」的話，下次還會再問，而且選項順序會對調。
- **線索**：它一直問；「一律採用」。
- **提示**：①「它每次都重新問一遍。」②「下面有兩個按鈕，差別在哪？」③「選 The Button，再按『一律採用』。」
- **備註**：誤選「Button 2＋一律採用」時，右上角的「偏好設定」裡有「清除預設值」。

### 90〈停用 Button 2〉（頭目）
- **任務**：停用 Button 2。
- **畫面與流程**：一段刻意拖延的退出流程，The Button 在旁邊用誠實的臉給方向。
  1. 設定頁捲到最底，展開「進階」，找到「停用 Button 2」。
  2. 確認框「我們會想念您 ✨」：主要按鈕是「留下」，文字按鈕才是「仍要停用」。
  3. 第二個確認框，兩顆按鈕的位置對調。
  4. 必填的單選題「停用原因」。
  5. 最後一步是「滑動以確認」。
- **解法**：每一步都看清楚按鈕上的字，不要看位置和顏色。
- **提示**：①「它不想讓妳走，所以每一步都在繞。」②「別看哪顆比較大、比較亮，看上面寫什麼。」③「設定最底 → 進階 → 停用；兩個確認框都選寫著『停用』的那顆；選一個原因；滑到底。」
- **通關台詞**：「……它其實沒有那麼壞。它只是沒有臉。」（實）
- **備註**：按到「留下」算錯，回到該步驟重來。

## 實作時的調整

- **The Button 的聲音**：這一章它的臉不見了，但它的台詞仍會出現在對話泡泡裡，只是泡泡不顯示臉。
- **〈空白的紀錄〉**：紀錄頁是關卡畫面裡的版本，匯入後列出前面幾條真實紀錄。
- **〈拼回來〉**：操作方式是點一塊碎片、再點它在臉上的位置。這是單指的做法，TalkBack 也能用。
- **〈兩個顧問〉**：Button 2 永遠說和 The Button 相反的那一句。
