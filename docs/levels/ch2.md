# 第 2 章　看我的臉（16–30）

**主題**：讀臉成為正式機制。說謊特徵本身不變（看旁邊＋一邊嘴角翹起），變的是「看得到多少」和「句子怎麼組合」。
**新介面**：這一章的 The Button 常以「聊天訊息」的形式說話。每則訊息旁有一個小頭像，頭像凍結在它說那句話當下的表情。
**共通規則**：
- 所有讀臉關都關閉 Host 的自動插話。
- 答錯回到該關的回合一，之後的回合隨機產生，但保證能從表情推出唯一解。
- 提示永遠是實話。
- 每關都能單指、不限時通關。

---

### 16〈顧問〉（已實作，id 6）
四回合讀臉：誇張的謊 → 實話 → 細微的謊 → 三選一的實話。

### 17〈開或關〉
- **任務**：把設定調成它要的樣子。
- **畫面**：三列 Switch（「讓我發光」「讓我安靜」「讓我休息」），每列右邊有「ⓘ」。下方是「套用」。
- **解法**：點每列的 ⓘ，它會說那一項要開還是關；依表情決定照做或反著做。三項都調對後按「套用」。
- **線索**：ⓘ 圖示；它每說一句，表情都不同。
- **提示**：①「每個開關旁邊都有一個小圖示。」②「它說要開的時候，眼睛看哪裡？」③「點 ⓘ 聽它說，看著妳就照做，看旁邊就反著做，最後按套用。」
- **台詞**：「這個要開。」（實或謊，隨機）／套用錯誤：「我要的不是這樣。……好吧，我剛剛沒說清楚。」
- **備註**：套用錯誤算一次錯，並重新隨機。

### 18〈太亮了〉
- **任務**：按下正確的按鈕。
- **畫面**：它戴著墨鏡，眼睛看不到。下方兩顆候選按鈕。畫面上方有一條「亮度」Slider（遊戲內的，不動系統亮度）。
- **解法**：把亮度拉到 30% 以下，它會摘下墨鏡，之後照常讀臉。三回合。
- **特殊解**：全程不碰亮度，只看嘴角過關。
- **線索**：進關台詞「這裡太亮了，我戴著墨鏡。」；亮度 Slider 就在畫面上。
- **提示**：①「它為什麼戴墨鏡？」②「畫面上有個東西可以讓這裡不那麼亮。」③「把亮度拉低，它會摘下墨鏡。或者只看嘴角：一邊翹起就是謊話。」
- **台詞**：摘下時「……好多了。」／特殊解「妳只看我的嘴就知道了？」

### 19〈重要公告〉
- **任務**：按下正確的按鈕。
- **畫面**：一條遊戲樣式的橫幅「我們重視妳的體驗」蓋住它的下半張臉，只看得到眼睛。兩顆候選按鈕。
- **解法**：只看眼睛判斷真假；或把橫幅往下滑掉（橫幅可以滑掉，每回合會再出現）。三回合。
- **線索**：橫幅邊緣有把手；它說「這東西擋到我的嘴了。」
- **提示**：①「它的嘴被擋住了，眼睛還在。」②「橫幅通常可以滑掉。」③「看它的眼睛：看旁邊就是謊話。也可以把橫幅往下滑。」
- **備註**：按橫幅上的「了解更多」只會讓它變長一行，不算錯。

### 20〈頭像〉
- **任務**：按下正確的按鈕。
- **畫面**：聊天畫面。它傳來訊息「是右邊。」，旁邊是 24dp 的小頭像。畫面中央沒有大的 The Button。下方兩顆候選。
- **解法**：點頭像放大檢視（聊天 App 的慣例），看清楚表情再選。三回合，舊訊息留在上方。
- **線索**：小頭像每則都略有不同；它說「我今天用傳的。」
- **提示**：①「它的臉變得好小。」②「聊天 App 裡，想看清楚對方的頭像會怎麼做？」③「點訊息旁的小頭像放大，看它說那句話時的表情。」
- **備註**：頭像的無障礙描述和大臉相同（「看向旁邊」等）。

### 21〈兩句話〉
- **任務**：按下正確的按鈕。
- **畫面**：聊天畫面，三顆候選（回合三是四顆）。它每回合傳一到三句，每句各有頭像。
- **解法**：把每句話依表情轉成真話，再合起來推出唯一解。
  - 回合一：「不是左邊，也不是右邊。」（實）→ 中間。
  - 回合二：「不是左邊，也不是右邊。」（謊）＋「不是左邊。」（實）→ 右邊。
  - 回合三：四顆候選、三句話。
- **線索**：一句話不夠時，它會說「等等，我還沒說完。」再補一句。
- **提示**：①「一句話不夠，就看兩句。」②「謊話反過來也是一條線索。」③「每一句都先依頭像判斷真假，再把剩下的可能刪掉。」
- **備註**：較早的訊息會捲上去，要往上捲才看得到。

### 22〈已編輯〉
- **任務**：按下正確的按鈕。
- **畫面**：一則訊息「是右邊。（已編輯）」，頭像是說謊臉。兩顆候選。
- **解法**：點「已編輯」看編輯紀錄：原本是「是左邊。」，頭像是誠實臉。以誠實的那一版為準。三回合，有時原文才是謊話。
- **線索**：「（已編輯）」字樣；它說「我剛剛改了一下說法。」
- **提示**：①「這則訊息被改過。」②「點『已編輯』可以看到原本寫什麼。」③「看兩個版本各自的頭像，相信看著妳的那一版。」
- **備註**：兩版都是謊話的回合，兩句反推的結果會指向同一顆。

### 23〈引用〉
- **任務**：按下正確的按鈕。
- **畫面**：它引用自己的上一則訊息（引用框裡只有文字「是左邊。」，沒有頭像），再回一句「我上一句是謊話。」，這句有頭像。
- **解法**：先判斷第二句的真假，再回推第一句。例如第二句是實話 → 第一句是謊 → 右邊。三回合。
- **線索**：引用框沒有頭像，只有回覆有。
- **提示**：①「被引用的那句話沒有臉。」②「有臉的那一句，在評論沒臉的那一句。」③「先看回覆的頭像判斷它是真是假，再決定被引用的那句能不能信。」

### 24〈同事〉
- **任務**：按下正確的按鈕。
- **畫面**：2×2 四顆候選。沒有臉的同事站在中間。下方有一排問題 Chip，只能問兩個：
  - 「在左半邊嗎？」
  - 「在上排嗎？」
  - 「哪一顆是正確的？」
  - 「你確定嗎？」
  The Button 在角落插嘴。
- **解法**：問「在左半邊嗎？」和「在上排嗎？」，同事只回是或不是，兩題就能定位。後兩個問題只會得到照字面的廢話（「正確的那一顆。」「是。」）。
- **線索**：The Button 用說謊臉說「問它哪一顆就好啦。」；問題只剩「2 次」的計數。
- **提示**：①「同事不會說謊，但它只照字面回答。」②「兩個問題，四顆按鈕。怎麼問才夠？」③「問『在左半邊嗎』和『在上排嗎』，別理 The Button 的建議。」
- **台詞**：同事「是。」「不是。」「正確的那一顆。」／The Button「它很無聊對吧。」（實）

### 25〈預覽〉
- **任務**：按下正確的按鈕。
- **畫面**：畫面上方滑下一張遊戲樣式的預覽卡，只有文字「是左邊。」，沒有臉。兩顆候選。
- **解法**：點預覽卡打開完整訊息，才看得到頭像，再判斷。三回合。只看預覽就選，遇到謊話回合會錯。
- **線索**：預覽卡右側有「展開」箭頭；它說「我有傳訊息給妳，妳有點開嗎？」
- **提示**：①「這則訊息只顯示了一部分。」②「預覽沒有臉。」③「點預覽卡打開完整訊息，看頭像再決定。」
- **備註**：預覽卡是遊戲自己的樣式，不模仿系統通知。

### 26〈限時動態〉
- **任務**：按下正確的按鈕。
- **畫面**：全螢幕的動態檢視，上方有三段進度條，每段是它說的一句話加表情，會自動播放並循環。下方三顆候選。
- **解法**：按住畫面可以暫停，點左半邊回上一段，點右半邊到下一段。三句話合起來推出唯一解。
- **線索**：進度條；它說「我只說一次。……騙妳的，會重播。」（實）
- **提示**：①「它說得很快，但會重播。」②「看動態的時候，按住畫面會怎樣？」③「按住暫停、點左邊回上一段，三句都依表情判斷後再選。」
- **備註**：會無限循環，所以沒有時間限制。開啟減少動態效果時不自動播放，改成點擊換段。

### 27〈貼圖〉
- **任務**：按下正確的按鈕。
- **畫面**：聊天畫面。妳用 Chip 提問（「是左邊嗎？」「是中間嗎？」「是右邊嗎？」），它只回貼圖：比讚或搖頭的 The Button。貼圖上的臉一樣有說謊特徵。
- **解法**：比讚＋說謊臉＝不是；搖頭＋說謊臉＝是。最多問兩題，再選。三回合。
- **線索**：貼圖的臉每張不同；它說「我今天不想打字。」
- **提示**：①「貼圖上也是它的臉。」②「比讚不一定是『是』。」③「看貼圖的眼睛：看旁邊就把意思反過來。」

### 28〈請稍候〉
- **任務**：按下按鈕。
- **畫面**：一條不確定進度的進度條和「請稍候…」，下方有「取消」。The Button 在旁邊說「再等一下就好了。不要按取消。」，是說謊臉。
- **解法**：它在說謊，進度條永遠不會跑完。按「取消」，進度條消失，它站出來讓妳按。
- **線索**：說謊臉；進度條是「不確定」樣式，沒有百分比。
- **提示**：①「這條進度條有在前進嗎？」②「它叫妳別按取消的時候，眼睛看哪裡？」③「它在說謊。按取消。」
- **台詞**：取消後「……妳現在連這個都看得出來了。」（實）
- **備註**：這是第一次把讀臉用在選擇題以外的地方。

### 29〈它說妳〉（記憶回扣）
- **任務**：更正它說錯的地方。
- **畫面**：它依序說三句關於妳的話，例如「妳在第 1 關花了 {x} 秒才按我。」。數字有的是真的，有的是它亂講的，表情會洩漏。每句下方有「沒錯」和「更正」；按「更正」會出現數字步進器。
- **解法**：誠實臉按「沒錯」。說謊臉按「更正」，到暫停選單的「紀錄」查出正確數字再填入。
- **線索**：表情告訴妳哪句錯，紀錄告訴妳正確的值，兩個都要用。紀錄上有小圓點。
- **提示**：①「它說的不全是真的。」②「哪一句是假的，看臉；正確答案在哪，妳去過。」③「說謊臉的那句按更正，去『紀錄』查數字填回來。」
- **使用的記憶**：第 1 關按壓延遲、錯誤總數、〈一個都不留〉之前的任一關耗時。

### 30〈三個我〉（頭目）
- **任務**：按下正確的按鈕。
- **畫面**：三個 The Button 並排，各說一句，下方三顆候選。三個分身各帶一種本章的閱讀條件：戴墨鏡、被橫幅擋嘴、縮成小頭像。
- **解法**：各自依條件讀臉，再合併推理。例：
  - A（墨鏡）：「是左邊。」（謊）
  - B（橫幅）：「不是中間。」（實）
  - C（小頭像）：「A 說的是實話。」（謊）
  - 結論：右邊。
  三回合。
- **線索**：本章每一種手法在這關都還能用：亮度 Slider、滑掉橫幅、放大頭像。
- **提示**：①「三個都是它，各有各的遮掩。」②「這一章學過的每一招，這裡都用得上。」③「調低亮度、滑掉橫幅、放大頭像，三句各自判斷真假，再合起來。」
- **通關台詞**：「妳現在看得懂我了。……這讓我有點不安。」（實）
