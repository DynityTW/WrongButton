# 第 7 章　後台（91–105）

**主題**：The Button 帶妳到介面的幕後。妳像開發者一樣調整介面來解謎。
**劇情**：「讓妳看看我是怎麼被做出來的。」
**共通畫面**：第 91 關之後，畫面底部多一個「後台」面板，裡面的工具逐關解鎖：版面邊界、圖層、屬性檢視、版面方向、字級、主題、動畫速度、規則。
**規則**：
- 所有「壞掉」的版面都是設計出來的狀態，不做假當機、假錯誤訊息。
- 後台工具只影響該關的畫面，不改系統設定。

---

### 91〈敲七下〉
- **任務**：打開後台。
- **畫面**：遊戲樣式的「關於」頁：名稱、版本 0.2.0、作者、授權。
- **解法**：連點「版本」那一列七下。第三下起，下方出現訊息「再按 4 下就能進入後台」。
- **線索**：它說「聽說有個地方，要敲七下門。」；倒數訊息。
- **提示**：①「這一頁有一列，點了會有反應。」②「它說要敲七下。」③「連點『版本』七下。」

### 92〈版面邊界〉
- **任務**：按下按鈕。
- **畫面**：看起來空白的畫面。後台面板有一個開關「顯示版面邊界」。
- **解法**：打開開關，每個元件都出現外框和類型標籤（Spacer、Text、Button）。點標著 Button 的那一塊。
- **線索**：它說「我在這裡，只是透明度是 0。」（實）
- **提示**：①「看不到，不代表不在。」②「後台有個工具可以把每個元件框出來。」③「打開『顯示版面邊界』，點標著 Button 的框。」

### 93〈圖層〉
- **任務**：按下按鈕。
- **畫面**：一張不透明的「公告」卡片蓋住整個中央，底下傳來「唔唔唔」。後台新增「圖層」清單：「公告卡片」排在「The Button」上面，每列有拖曳把手和眼睛圖示。
- **解法**：把「The Button」那一層拖到最上面，或關掉「公告卡片」的眼睛。
- **線索**：卡片的陰影；悶住的聲音；呼應第 8 關（排第一）。
- **提示**：①「它被蓋住了。」②「圖層清單的順序，就是誰蓋住誰。」③「把 The Button 那一層拖到最上面，或關掉公告卡片的眼睛。」

### 94〈屬性〉
- **任務**：按下按鈕。
- **畫面**：The Button 看得到但是停用的。後台新增「屬性檢視」：點選元件後列出 enabled、visible、alpha、clickable。
- **解法**：兩步。
  1. 選取 The Button，勾選 enabled。
  2. 還是按不到。打開版面邊界，會發現上面蓋著一個透明的 Box（clickable），選取它並取消 clickable。
- **線索**：勾了 enabled 還按不到時，它說「妳的手指沒有碰到我。有東西擋在中間。」（實）
- **提示**：①「它是停用的。哪裡可以改？」②「改好了還是按不到，再用上一關的工具看看。」③「勾選它的 enabled；打開版面邊界，選取上面那個透明 Box，取消 clickable。」

### 95〈算數〉（記憶回扣）
- **任務**：按下按鈕。
- **畫面**：The Button 只有 16dp（和〈至少 48dp〉一樣）。屬性檢視多了一項「最小觸控範圍：0dp」，可以用步進器調整。
- **解法**：把最小觸控範圍調到 48dp。外觀仍是 16dp，但打開邊界可以看到觸控範圍變大，按得到了。
- **線索**：它說「這次不用撐大我。只要讓我『算數』就好。」
- **提示**：①「它還是那麼小，但這次妳有別的工具。」②「規範說的是觸控範圍，不是外觀。」③「選取它，把『最小觸控範圍』調到 48dp 再按。」
- **台詞**：通關後依〈至少 48dp〉的解法吐槽（「上次妳用兩根手指把我撐開。這樣文明多了。」）

### 96〈方向〉
- **任務**：按下按鈕。
- **畫面**：一橫列的同事。The Button 在這一列的最尾端，在畫面外。這一列不能捲動。後台新增「版面方向：由左至右／由右至左」。
- **解法**：切成由右至左，整列鏡像，尾端跑到畫面內。也可以在屬性檢視把這一列的「可捲動」打勾。
- **線索**：列尾露出一點點珊瑚紅；它說「我在這一列的最後面。」（實）
- **提示**：①「它在這一列的尾巴，在畫面外。」②「如果『尾巴』換到另一邊呢？」③「把版面方向切成『由右至左』，或勾選這一列的『可捲動』。」

### 97〈小字〉
- **任務**：按下按鈕。
- **畫面**：The Button 下方有一行小到看不清的字。直接按它，它說「怎麼按我，寫在下面。」後台新增「字級」Slider。
- **解法**：把字級拉到最大，小字變成「請長按」。長按它。
- **線索**：那行小字；字級 Slider。
- **提示**：①「下面有一行字，太小了。」②「後台可以調字的大小。」③「把字級拉到最大，照上面寫的做：長按我。」
- **備註**：TalkBack 會直接讀出小字的內容。

### 98〈白底白字〉
- **任務**：按下按鈕。
- **畫面**：一張白色卡片蓋住 The Button，卡片上看起來什麼都沒有。後台新增「主題：淺色／深色」。
- **解法**：切成深色。卡片右上角原本是白底白色的「×」，現在看得到了，按它關掉卡片。
- **線索**：它說「做這張卡片的人，忘了在淺色模式下測試。」（實）
- **提示**：①「這張卡片應該有個關閉鈕。」②「白色的東西放在白色上面，會怎樣？」③「把主題切成深色，按卡片右上角出現的『×』。」
- **備註**：「×」在淺色下也能點，矇到算特殊解。TalkBack 讀得到「關閉」。

### 99〈裁切〉
- **任務**：按下按鈕。
- **畫面**：一張小卡片的邊緣露出一小條珊瑚紅。The Button 大部分在卡片範圍外，被裁掉了。
- **解法**：選取卡片，在屬性檢視取消「裁切超出範圍的內容」。它整個露出來，就能按了。
- **線索**：那一小條顏色；它說「我有一大半被切掉了。」（實）
- **提示**：①「卡片邊緣那一條紅色是什麼？」②「是誰把超出去的部分切掉的？」③「選取那張卡片，取消『裁切超出範圍的內容』。」

### 100〈太快了〉
- **任務**：按下按鈕。
- **畫面**：The Button 在畫面上來回移動，快到很難按中。後台新增「動畫速度：1×／0.5×／0.1×／暫停」。
- **解法**：調到 0.1× 或暫停，再按。
- **線索**：它說「妳抓不到我的。除非有人讓時間慢下來。」
- **提示**：①「它太快了。」②「後台可以控制動畫的速度。」③「把動畫速度調到 0.1× 或暫停，再按我。」
- **備註**：開啟減少動態效果時，它改成每秒跳一個位置，不做連續的高速移動，解法相同。直接按中算特殊解。

### 101〈記住狀態〉
- **任務**：按 10 下。
- **畫面**：計數「0／10」。每按一下加一，但到 7 左右，畫面會重新配置一次（一個旋轉的轉場），計數回到 0。它說「啊，我忘了數到哪。每次轉一下我就忘。」
- **解法**：選取計數器，在屬性檢視勾選「記住狀態」。之後重新配置也不會歸零，按到 10。
- **線索**：它直接說了問題在哪；屬性檢視。
- **提示**：①「它每次都在同一個時候忘記。」②「有個屬性可以讓它在轉場後還記得。」③「選取計數器，勾選『記住狀態』，再按到 10。」
- **台詞**：通關後「原來只要有人幫我記住就好。」（實）
- **備註**：重新配置是設計好的轉場動畫，不是當機，也不顯示任何錯誤訊息。

### 102〈0dp〉
- **任務**：按下按鈕。
- **畫面**：一橫列：一張佔滿整列的橫幅，和一條極細的直線。打開版面邊界看得出那條線是「Button（寬度 0dp）」。
- **解法**：選取它，把寬度調到 48dp 以上。橫幅自動縮短，它出現了。
- **線索**：那條細線；邊界的標籤。
- **提示**：①「橫幅旁邊有一條很細的線。」②「打開版面邊界，看看那條線是什麼。」③「選取那條線，把寬度調到 48dp 以上。」

### 103〈規則〉
- **任務**：按下按鈕。
- **畫面**：按它，它就生氣，沒有通關。後台新增「規則」清單，由上往下判斷，符合就停：
  1. 「如果被按 → 生氣」
  2. 「如果被按，而且心情不是生氣 → 通關」
- **解法**：把第 2 條拖到第 1 條上面，或關掉第 1 條的開關。
- **線索**：規則旁的說明「由上往下，符合就停」。
- **提示**：①「它為什麼每次都生氣？」②「規則是有順序的。」③「把『通關』那一條拖到最上面，或關掉『生氣』那一條。」

### 104〈信任值〉（記憶回扣）
- **任務**：把信任值調到 1。
- **畫面**：後台顯示它的記憶檔，是真實的資料、唯讀的鍵值清單。最下面一列是「trust：0.40」，有一個 Slider。
- **解法**：
  - Slider 拉了會彈回去。它說「這個不能用改的。」（實）
  - 它接著說話，每句各帶表情：
    - 誠實臉「按我。」→ 按它。
    - 說謊臉「別按我。」→ 也是按它。
    - 誠實臉「現在先不要按。」→ 等它說下一句。
  - 每做對一次加 0.2，三次到 1。
- **線索**：Slider 會彈回；它說「這個要用別的方法。」
- **提示**：①「這個數字，後台改不了。」②「信任不是調出來的。聽它說話，看它的臉。」③「它說實話就照做，說謊就反著做。做對三次。」
- **備註**：做錯會扣 0.2。這是後台工具唯一失效的一關，為最終章鋪路。

### 105〈重組〉（頭目）
- **任務**：按下按鈕。
- **畫面**：一個被拆散的畫面，上方的計數 Chip 寫著「尚有 4 個問題」（呼應〈一個都不留〉）。
- **解法**：把四個問題各自修好，每修好一個計數減一。
  1. 它被卡片蓋住 → 調整圖層。
  2. 它是停用的 → 屬性。
  3. 它在不能捲動的那一列尾端 → 版面方向。
  4. 它的觸控範圍是 0dp → 最小觸控範圍。
- **提示**：①「四個問題，妳都見過。」②「一次處理一個：誰蓋住它、它能不能按、它在哪、碰不碰得到。」③「圖層拉到最上面、勾 enabled、方向改成由右至左、觸控範圍調到 48dp。」
- **通關台詞**：「妳現在知道我是什麼做的了。……妳還是想按我嗎？」（實）

## 實作時的調整

- **後台面板**：每一關的面板只放那一關要用的工具，沒有做成一路累積的固定面板。面板是遊戲自己的深色等寬字樣式，不像系統的開發者選項。
- **〈圖層〉、〈規則〉、〈重組〉**：「拖曳」改成每列的「↑ 上移」按鈕。單指可用，TalkBack 也能操作。
- **〈屬性〉**：透明的 Box 只有在打開版面邊界之後，才會出現在屬性檢視的選取列裡。
- **〈算數〉**：觸控範圍小於 48dp 時按它，它說「不算數」，不算錯。
- **〈方向〉**：同事的數量會跟著螢幕寬度增加，所以橫向或平板上 The Button 也一定在畫面外。
- **〈太快了〉**：在 1× 速度下直接按中算特殊解。
- **〈信任值〉**：
  - 它說的句子顯示在它旁邊的卡片上，臉是它本人的臉。
  - 除了設計中的三種句子，之後還會出現說謊的「按我。」（要等）。
  - 要等的句子，等 4 秒就算做對；要按的句子沒有時間限制。
  - 記憶檔列出的是真實資料：通關數、錯誤總數、稱呼、第 1 關秒數。
