# 第 10 章　同類（136–150）

> 由 `tools/s2/gen.py` 依 `tools/s2/ch10.py` 產生。

**主題**：其他會說話的元件登場：開關、滑桿、勾勾、圓鈕，章末還有新來的分頁。每個角色都有**自己的**說謊特徵，要靠玩家自己觀察出來。The Button 的說謊特徵仍然永遠不變。

| 角色 | 說實話 | 說謊 |
|---|---|---|
| 開關 | 滑塊在盡頭 | 滑塊停在中間 |
| 滑桿 | 數字和滑塊的位置一樣 | 數字和滑塊的位置不一樣 |
| 勾勾 | 勾是正的 | 勾是反的 |
| 圓鈕 | 圓點在正中間 | 圓點偏到一邊 |
| 分頁 | 底線在字的正下方 | 底線歪到旁邊 |

**本章規則**：
- 每個角色先用一關「教」：畫面上看得到答案（幾盞燈亮著），玩家可以自己對照出它說謊時長什麼樣子。之後才用在看不到答案的回合裡。
- TalkBack 讀得到每個角色的外觀描述（例如「滑塊停在中間」），但不會直接說「它在說謊」。
- 答錯回到回合一，內容重新隨機，但一定能從外觀推出唯一解。
- 章內回扣：第 149 關問第 147 關第一回合說謊的是誰（紀錄頁有記）。

### 136〈新同事：開關〉
- **任務**：它說的是真話還是假話？
- **畫面**：上方是三盞燈（亮或暗，隨機），角色說一句關於燈的話，玩家判斷它說的是真話還是假話。四回合。
- **解法**：對照燈的亮暗，判斷真假。回答時順便記住它說謊時的樣子。
- **線索**：燈本身就是答案；開關說謊時滑塊停在中間。
- **提示**：①「對照上面的燈，開關說的對不對？」②「注意開關說假話時，樣子有哪裡不一樣。」③「開關說謊時，滑塊停在中間；說實話時，滑塊在盡頭。」
- **備註**：答錯回到回合一。這一關是教學：每回合都看得到答案，讓玩家自己對照出說謊特徵。

### 137〈開關的建議〉
- **任務**：按下正確的按鈕。
- **畫面**：開關站在兩顆候選按鈕上方，說「是左邊」或「是右邊」。四回合。
- **解法**：滑塊停在中間代表它在說謊，選另一顆；滑塊在盡頭就照它說的選。
- **線索**：開關的滑塊位置。
- **提示**：①「開關會告訴妳是哪一顆。」②「它的話可能是假的。」③「滑塊停在中間就是謊話，選另一顆；在盡頭就照它說的選。」

### 141〈勾勾的建議〉

### 144〈兩個顧問〉
- **任務**：按下正確的按鈕。
- **畫面**：開關和滑桿各說一句話，三顆候選。三回合。
- **解法**：各自用自己的說謊特徵判斷真假，合起來只剩一顆。
- **線索**：開關的滑塊、滑桿的數字。
- **提示**：①「兩個顧問各說一句。」②「它們說謊的樣子不一樣。」③「開關看滑塊，滑桿看數字。各自判斷真假，再合起來。」

### 145〈它說它說謊〉
- **任務**：按下正確的按鈕。
- **畫面**：滑桿說「是左邊／右邊」，但它的數字被貼紙蓋住了。開關在旁邊說「滑桿說的是實話／謊話」。兩顆候選，三回合。
- **解法**：先用開關的滑塊判斷開關的真假，推出滑桿的真假，再決定選哪一邊。
- **線索**：貼紙；開關的滑塊。
- **提示**：①「滑桿的數字被貼紙蓋住了。」②「開關說的是「滑桿說的是不是實話」。」③「先看開關的真假，就知道滑桿的真假，再決定選哪一邊。」

### 146〈群組〉
- **任務**：按下正確的按鈕。
- **畫面**：群組聊天：三個角色各傳一則訊息，頭像停在說話當下的樣子。四顆候選，三回合。
- **解法**：每則訊息依說話者的特徵判斷真假，三句合起來只剩一顆。
- **線索**：每則訊息的頭像。
- **提示**：①「群組裡三個人各說一句。」②「每個人說謊的樣子不一樣。」③「一句一句判斷真假（看頭像），合起來只剩一顆。」

### 147〈誰在說謊〉
- **任務**：按下說謊的那一個。
- **畫面**：四個角色排成一排，各說一句閒聊。只有一個在說謊。三回合。
- **解法**：依每個角色的特徵找出說謊的那一個，按它。
- **線索**：四種說謊特徵。
- **提示**：①「四個角色裡，只有一個在說謊。」②「內容不重要，看樣子。」③「開關停在中間、滑桿數字對不上、勾是反的、圓點偏掉——找出那一個。」
- **備註**：第一回合說謊的是誰會記在紀錄裡，第 149 關會問。

### 148〈新來的〉
- **任務**：它說的是真話還是假話？最後一題，按下正確的按鈕。
- **畫面**：前兩回合：三盞燈＋分頁說一句關於燈的話，判斷真假。後兩回合：燈不見了，分頁說是哪一顆（兩顆候選）。
- **解法**：先從前兩回合找出分頁說謊時的樣子（底線歪掉），再用在後兩回合。
- **線索**：燈；分頁的底線。
- **提示**：①「分頁是新來的，沒人知道它說謊的樣子。」②「前兩回合看得到燈，可以自己對照。」③「分頁說謊時，底線會歪到旁邊。」
- **備註**：這一關把整章的技巧濃縮成一關：自己找出新角色的說謊特徵。

### 149〈記得誰〉
- **任務**：第 147 關，第一回合說謊的是誰？
- **畫面**：四個角色排成一排（都說實話的樣子）。
- **解法**：從紀錄頁讀出第 147 關第一回合說謊的角色，按它。
- **線索**：暫停選單的「紀錄」有小圓點。
- **提示**：①「答案在紀錄裡。」②「暫停選單 →「紀錄」。」③「紀錄裡寫著第 147 關第一回合說謊的角色，按它。」
- **備註**：章內回扣。紀錄被滑掉時，用預設答案（滑桿）並重新記下。

### 150〈三方會談〉
- **任務**：按下正確的按鈕。
- **畫面**：開關、滑桿、勾勾和 The Button 各說一句。四顆候選，三回合。
- **解法**：依各自的說謊特徵判斷每一句的真假，合起來只剩一顆。
- **線索**：四種說謊特徵（The Button 的永遠不變）。
- **提示**：①「四個角色各說一句，包括我。」②「每個角色用自己的方式說謊。」③「一句一句判斷：開關看滑塊、滑桿看數字、勾勾看勾、我看眼睛和嘴角。」
- **備註**：章末頭目。
