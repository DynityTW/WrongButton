# 第 9 章　外面（121–135）

> 由 `tools/s2/gen.py` 依 `tools/s2/ch09.py` 產生。

**主題**：The Button 發現螢幕外面還有一支真的手機。這一章的「按鈕」是真的系統功能：實體音量鍵、旋轉、深色主題、字級、飛航模式、離開 App、長按圖示的捷徑、桌面小工具、靜音。

**本章規則**：
- 全部是真的系統功能，不是假的系統畫面。畫面上永遠是遊戲自己的樣式。
- 都不需要任何權限。音量鍵只在需要它的關卡裡被遊戲攔下來，其他時候照常調整音量。
- 每一關都有遊戲內的替代路徑或清楚的提示：深色主題可以用系統設定，也可以用遊戲自己的「設定 → 主題」。
- 獨立章節：只假設玩家會第一季教過的東西。章內回扣只用本章的紀錄（第 123 關的暗號）。

---

### 121〈外面〉
- **任務**：按下按鈕。
- **畫面**：畫面中央是一張 The Button 的「照片」，旁邊畫著手機的側面，側邊的音量鍵被圈起來。
- **解法**：按一下實體音量鍵（上下都可以）。
- **線索**：手機側面圖上被圈起來的按鍵；照片下面寫著「（這是照片）」。
- **提示**：①「我不在螢幕上。」②「手機側邊有兩顆實體按鍵。」③「按一下側邊的音量鍵。」
- **備註**：點照片算錯。這一關的音量鍵會被遊戲攔下來，不會改到系統音量。

### 122〈小聲一點〉
- **任務**：按下按鈕。
- **畫面**：The Button 用很大的字在喊。上方是遊戲內的音量條，從 5 格開始。
- **解法**：按五次實體音量「下」，音量條歸零後按 The Button。
- **線索**：音量條會跟著實體音量鍵增減；它的字越來越小。
- **提示**：①「它太大聲了。」②「畫面上的音量條跟著實體按鍵走。」③「按五次音量「下」，等它小聲了再按它。」
- **備註**：音量「上」會讓它更大聲，但不算錯。音量條歸零前按它算錯。

### 123〈暗號〉
- **任務**：照它的暗號，用側邊的按鍵按一次。
- **畫面**：四個箭頭排成一列（▲ 或 ▼，隨機），下方是輸入進度。
- **解法**：依序按實體音量鍵：▲＝音量上、▼＝音量下。
- **線索**：箭頭方向和音量鍵的上下一致。
- **提示**：①「▲ 和 ▼ 是兩顆實體按鍵。」②「▲ 是音量上，▼ 是音量下。」③「照順序按：▲ 按音量上、▼ 按音量下，按錯會從頭來。」
- **備註**：按錯一個算錯、從頭來。暗號記在紀錄裡，第 133 關會用到。點畫面上的箭頭算錯。

### 124〈躺著〉
- **任務**：按下按鈕。
- **畫面**：The Button 橫躺在畫面中央，旁邊有一個「旋轉」的小圖示。
- **解法**：把手機轉成橫向，它就站起來了，再按它。
- **線索**：它是橫躺的；旁邊的小字寫「自動旋轉要打開」。
- **提示**：①「它是橫著躺的。」②「把手機轉過來，讓它站起來。」③「把手機轉成橫的（記得打開自動旋轉），再按它。」
- **備註**：直向時按它算錯。關卡狀態在旋轉時會保留。

### 125〈轉一圈〉
- **任務**：按下按鈕。
- **畫面**：The Button 在中央，下方顯示「轉了 0／2 次」。
- **解法**：把手機轉成另一個方向、再轉回來（方向改變兩次），然後按它。
- **線索**：計數會在每次轉向時加一。
- **提示**：①「它想看妳把手機轉來轉去。」②「轉成橫的，再轉回直的。」③「轉兩次方向（橫過來、再轉回來），然後按它。」
- **備註**：計數只算方向真的改變的次數，從哪個方向開始都可以。

### 126〈關燈〉
- **任務**：按下按鈕。
- **畫面**：The Button 穿著睡衣，旁邊有一盞燈，寫著「燈：開」。
- **解法**：把主題換成深色（系統的深色主題，或遊戲的「設定 → 主題 → 深色」），再按它。
- **線索**：「燈：開」；它說太亮了。
- **提示**：①「它說太亮了，睡不著。」②「把畫面換成深色。」③「打開系統的深色主題，或到遊戲的「設定 → 主題」選深色，再回來按它。」
- **備註**：系統沒有深色主題的手機（Android 9 以下）可以用遊戲自己的主題設定。離開關卡去設定再回來也可以。

### 127〈字太小〉
- **任務**：按下按鈕。
- **畫面**：它的對話泡泡用非常小的字。
- **解法**：到系統設定把字型大小調大（比進關時大），回來後按它。
- **線索**：泡泡裡的字小到幾乎看不見；放大後寫著「現在可以按我」。
- **提示**：①「它說的話小到看不清楚。」②「系統可以把所有字放大。」③「到系統設定把字型大小調大，回來它就看得清楚了，再按它。」
- **備註**：判斷方式是「比進關時的字級大」，原本就用大字的玩家也一樣要再調大一級。

### 128〈安靜一下〉
- **任務**：按下按鈕。
- **畫面**：The Button 摀著耳朵，旁邊畫著一架小飛機，寫著「訊號：有」。
- **解法**：打開系統的飛航模式，再按它。
- **線索**：小飛機圖示；「訊號：有」。
- **提示**：①「它不想要任何訊號進來。」②「有一個開關可以一次切掉所有無線訊號。」③「打開飛航模式，再按它。（這個遊戲本來就不用網路。）」
- **備註**：遊戲本身不連網，所以飛航模式不會影響遊戲。通關台詞提醒玩家可以關掉。

### 129〈出去一下〉
- **任務**：按下按鈕。
- **畫面**：一扇掛著「請勿打擾」的門，The Button 躲在後面。
- **解法**：離開 App（回到桌面或切換到別的 App），再回來按它。
- **線索**：「請勿打擾」；它說「妳先出去」。
- **提示**：①「它要妳出去一下。」②「不是離開關卡，是離開 App。」③「回到桌面（或切到別的 App），再回來按它。」
- **備註**：和第 53 關〈草稿〉不同：這次要離開的是 App，不是關卡。按系統返回會回到選關，關卡會重來。

### 130〈從外面按我〉
- **任務**：按下按鈕。
- **畫面**：一張示意圖：App 圖示被長按，跳出選單「按下 The Button」。
- **解法**：回到桌面，長按 Wrong Button 的圖示，選捷徑「按下 The Button」。遊戲會打開並直接回到這一關。
- **線索**：示意圖裡的選單文字。
- **提示**：①「桌面上也有一個我。」②「長按桌面上的 App 圖示，會出現捷徑。」③「回桌面，長按 Wrong Button 的圖示，選「按下 The Button」。」
- **備註**：捷徑是真的系統捷徑（不需要權限）。就算 Activity 被重建，按下的紀錄也記在記憶裡，回來後一樣通關。

### 131〈放在桌面〉
- **任務**：按下按鈕。
- **畫面**：示意圖：桌面上的一個小工具，裡面是 The Button。
- **解法**：把遊戲的小工具「The Button」放到桌面，點它。
- **線索**：示意圖；小工具清單裡有「The Button」。
- **提示**：①「它想住在桌面上。」②「桌面可以放小工具。」③「長按桌面空白處 →「小工具」→ 找到 The Button，放上桌面，再按它。」
- **備註**：小工具不需要權限，也不定時更新。

### 132〈別碰螢幕〉
- **任務**：只用側邊的按鍵，選出 The Button。
- **畫面**：一份四項的清單（三個同事和 The Button，順序隨機），其中一項被框起來。上方寫「▼ 移動　▲ 按下」。
- **解法**：按音量「下」把框移到 The Button，按音量「上」選取。
- **線索**：上方的圖例。
- **提示**：①「這一關不能碰螢幕。」②「音量下可以移動選取。」③「音量「下」移到 The Button，音量「上」按下去。」
- **備註**：點螢幕上的任何一項都算錯。選到同事算錯。

### 133〈倒過來〉
- **任務**：把上次的暗號倒過來按一次。
- **畫面**：暗號被蓋住了（？？？？），只顯示輸入進度。
- **解法**：從紀錄頁讀出第 123 關的暗號，倒過來依序按音量鍵。
- **線索**：暫停選單的「紀錄」有小圓點；紀錄頁記著暗號。
- **提示**：①「暗號是第 123 關的那一組。」②「紀錄裡記著上次的暗號。」③「到「暫停 → 紀錄」看暗號，從最後一個往前按。」
- **備註**：本章的章內回扣。沒有紀錄時（例如被滑掉）用預設暗號 ▲▲▼▲，並在紀錄頁重新記下。

### 134〈靜音〉
- **任務**：按下按鈕。
- **畫面**：喇叭圖示，寫著「聲音：開」。
- **解法**：把媒體音量調到 0，或把手機切成靜音／震動，再按它。
- **線索**：喇叭圖示；「聲音：開」。
- **提示**：①「它想聽妳說話。」②「把整支手機調成靜音。」③「把媒體音量調到 0（或把手機切成靜音／震動），再按它。」
- **備註**：這一關不攔音量鍵，按側邊按鍵會真的改系統音量。和第 122 關（遊戲內的音量條）不同。

### 135〈外面的世界〉
- **任務**：照順序做完，最後按它。
- **畫面**：五個步驟的清單，完成的會打勾。
- **解法**：依序：轉成橫的 → 音量上 → 轉回直的 → 音量下 → 按 The Button。
- **線索**：清單本身。
- **提示**：①「清單上的步驟要照順序。」②「轉向、音量鍵，都是螢幕外面的事。」③「橫過來 → 按音量上 → 轉回直的 → 按音量下 → 按它。」
- **備註**：章末頭目。音量鍵按錯順序算錯並從頭來；轉向不會算錯。進關時已經是橫的，第一步會直接打勾。
