# 第 17 章　設定（241–255）

> 由 `tools/s2/gen.py` 依 `tools/s2/ch17.py` 產生。

**主題**：設定頁。The Button 變成一個設定項目，要妳找到它、讓它可以按，再按下去。

畫面是一個遊戲內的「The Button 設定」App（遊戲自己的樣式，不是手機的系統設定）：分類、子頁面、開關、單選、滑桿、收起來的「進階」、搜尋、恢復預設值、需要重新啟動的設定。

**本章規則**：
- The Button 那一列在條件沒達成時是停用的，並寫出原因（例如「需要先開啟『顯示按鈕』」）。
- 停用的開關也會寫出它需要什麼。照著原因一路往回找就對了。
- 章內回扣：第 254 關問第 241 關 The Button 在哪個分類（紀錄頁有記）。

---

### 241〈設定〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：設定首頁有三個分類：顯示、聲音、通知。
- **解法**：點進去找到「The Button」那一列，按它。
- **線索**：分類名稱。
- **提示**：①「我在某個分類裡面。」②「每個分類點進去都看看。」③「其中一個分類的最下面就是我（顯示、聲音、通知之一）。」
- **備註**：我在哪個分類（隨機）會記在紀錄裡，第 254 關會問。

### 242〈很深〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：設定首頁：一般、系統、關於。
- **解法**：系統 → 進階 → 實驗功能 → The Button。
- **線索**：每一頁的分類名稱。
- **提示**：①「我藏得很深。」②「一層一層點進去。」③「系統 → 進階 → 實驗功能 → The Button。」

### 243〈搜尋〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：設定首頁有很多分類，最上面有搜尋框。
- **解法**：在搜尋框打「Button」，點搜尋結果，再按 The Button。
- **線索**：搜尋框。
- **提示**：①「分類太多了。」②「上面有搜尋框。」③「搜尋「Button」或「按鈕」，點搜尋結果。」
- **備註**：一個一個分類點進去也找得到，只是比較久。

### 244〈先開這個〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：首頁就有 The Button，但是停用的，寫著「需要先開啟『顯示按鈕』」。
- **解法**：到「顯示」打開「顯示按鈕」，回來按 The Button。
- **線索**：停用原因。
- **提示**：①「我是停用的。」②「下面寫了原因。」③「先到「顯示」打開「顯示按鈕」，再回來按我。」

### 245〈連鎖〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：The Button 需要「動畫」，動畫需要「特效」，特效需要「顯示卡加速」。
- **解法**：依序打開：顯示卡加速 → 特效 → 動畫，再按 The Button。
- **線索**：停用原因。
- **提示**：①「我需要 A，A 需要 B，B 需要 C。」②「每個停用的開關都寫了原因。」③「照原因往回找：先開最底層的那一個，再一路往上。」

### 246〈進階〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：「顯示」頁最下面有一個收起來的「進階 ▸」。
- **解法**：點開「進階」，按 The Button。
- **線索**：收起來的區塊。
- **提示**：①「這一頁好像沒有我。」②「最下面有一個收起來的區塊。」③「點開「進階」，我在裡面。」

### 247〈被亂調了〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：很多開關都被調過，The Button 停用，寫著「設定異常」。最下面有「恢復預設值」。
- **解法**：按「恢復預設值」，再按 The Button。
- **線索**：恢復預設值。
- **提示**：①「有人把我的設定亂調了。」②「一個一個改回來很累。」③「按最下面的「恢復預設值」，再按我。」

### 248〈只能選一個〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：「安靜模式」開著，The Button 停用，寫著「安靜模式開啟時無法使用」。
- **解法**：關掉安靜模式，按 The Button。
- **線索**：停用原因。
- **提示**：①「安靜模式開著的時候，我不能用。」②「兩個不能同時開。」③「關掉「安靜模式」，再按我。」

### 249〈位置〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：單選設定「The Button 的位置」：隱藏（目前）、左邊、右邊。
- **解法**：改成左邊或右邊，按出現的 The Button。
- **線索**：單選的選項。
- **提示**：①「我的位置被設成「隱藏」。」②「改成別的位置。」③「把「The Button 的位置」改成左邊或右邊，我就會出現。」

### 250〈大一點〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：「顯示大小」滑桿在 1。The Button 停用，寫著「太小了，按不到」。
- **解法**：把顯示大小拉到 3 以上，按 The Button。
- **線索**：停用原因；滑桿。
- **提示**：①「我太小了，看不到。」②「有一個顯示大小的設定。」③「把「顯示大小」拉到 3 以上，再按我。」

### 251〈語言〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：「語言」單選：中文（目前）、English、日本語、按鈕語。The Button 停用，寫著「此語言不支援」。
- **解法**：改成「按鈕語」，按 The Button。
- **線索**：停用原因；語言清單。
- **提示**：①「我只在某一種語言裡出現。」②「語言清單裡有一個很眼熟的。」③「把語言改成「按鈕語」，我就會出現。」

### 252〈重新啟動〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：開關「啟用 The Button」。改了之後上方出現「需要重新啟動才會生效」和「立即重新啟動」。
- **解法**：打開開關，按「立即重新啟動」，按 The Button。
- **線索**：重新啟動的提示。
- **提示**：①「改完要重新啟動才會生效。」②「上面會跳出提示。」③「打開「啟用 The Button」，按提示的「立即重新啟動」，再按我。」
- **備註**：這裡的重新啟動只是設定頁裡的模擬，不會真的重開 App。

### 253〈權限〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：The Button 停用，寫著「需要『允許被按』權限」。
- **解法**：到「App 權限」打開「允許被按」，按 The Button。
- **線索**：停用原因。
- **提示**：①「我沒有被允許。」②「App 權限裡有一個開關。」③「到「App 權限」打開「允許被按」，再按我。」
- **備註**：這是遊戲裡設定頁的開關，不是手機真正的權限，遊戲不會要求任何系統權限。

### 254〈哪個分類〉
- **任務**：第 241 關，我在哪個分類？
- **畫面**：三個選項：顯示、聲音、通知。
- **解法**：從紀錄頁讀出分類。
- **線索**：暫停選單的「紀錄」有小圓點。
- **提示**：①「第 241 關我在哪個分類？」②「紀錄裡有。」③「暫停 →「紀錄」看第 241 關的分類。」
- **備註**：章內回扣。沒有紀錄時當作「通知」並重新記下。

### 255〈設定大師〉
- **任務**：找到 The Button 這個設定，按下去。
- **畫面**：很多分類加搜尋框。The Button 停用，需要「啟用 The Button」（在進階裡、需要重新啟動），而它又需要「特效」，特效需要「顯示卡加速」。
- **解法**：依停用原因：顯示卡加速 → 特效 → 進階的啟用 The Button → 立即重新啟動 → 按 The Button。
- **線索**：停用原因；搜尋框。
- **提示**：①「搜尋、進階、連鎖、重新啟動，全部都有。」②「照停用原因一路往回找。」③「搜尋「顯示卡」打開它 → 打開「特效」→ 展開進階打開「啟用 The Button」→ 立即重新啟動 → 按我。」
- **備註**：章末頭目。
